# FoundationDB Dashboard

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **Русский** | [日本語](README.ja.md) | [Deutsch](README.de.md) | [Français](README.fr.md)

Неофициальная веб-консоль для кластеров FoundationDB в Docker. Один образ содержит интерфейс и клиент FoundationDB **7.3.62**. База данных остаётся снаружи.

FoundationDB: [github.com/apple/foundationdb](https://github.com/apple/foundationdb)  
Образ: [hub.docker.com/r/runu/foundationdb-dashboard](https://hub.docker.com/r/runu/foundationdb-dashboard)

## Быстрый старт

```bash
docker run --rm \
  -p 127.0.0.1:8090:8080 \
  --network local-foundationdb_default \
  -e FDB_CONNECTION_STRING=docker:docker@foundationdb:4500 \
  runu/foundationdb-dashboard:7.3.62
```

Если кластер уже запущен через Compose:

```bash
docker compose up -d
```

Откройте [http://127.0.0.1:8090/](http://127.0.0.1:8090/).

Публикуйте порт только на `127.0.0.1`. Процесс слушает `PORT` (по умолчанию `8080`).

## Конфигурация

| Переменная | Обязательно | Описание |
| --- | --- | --- |
| `FDB_CONNECTION_STRING` | одно из двух | Строка подключения, например `docker:docker@foundationdb:4500` |
| `FDB_CLUSTER_FILE` | одно из двух | Путь к cluster-файлу в контейнере. Имеет приоритет, если заданы оба |
| `PORT` | нет | Порт внутри контейнера (по умолчанию `8080`) |
| `TREND_FILE` | нет | Путь к буферу тренда чтения/записи за 24 часа |
| `CLUSTERS_FILE` | нет | Путь к сохранённому каталогу кластеров |
| `AUTH` | нет | `on` / `off` (по умолчанию выкл.). При `on` нужны пользователь и пароль |
| `AUTH_USER` | при auth | Имя пользователя (до 64 символов) |
| `AUTH_PASSWORD` | при auth | Пароль (до 256 символов) |

Пример со входом:

```bash
docker run --rm \
  -p 127.0.0.1:8090:8080 \
  --network local-foundationdb_default \
  -e FDB_CONNECTION_STRING=docker:docker@foundationdb:4500 \
  -e AUTH=on \
  -e AUTH_USER=admin \
  -e AUTH_PASSWORD=secret \
  runu/foundationdb-dashboard:7.3.62
```

## Страницы

### Обзор

![Обзор](docs/imgs/overview.png)

Доступность кластера, состояние данных, восстановление, избыточность, движок хранения, координаторы, процессы и роли, нагрузка чтения/записи, задержки и устойчивость к отказам. Данные из `\xff\xff/status/json`, обновление примерно каждые 3 секунды, пока вкладка видима. График пишется в фоне каждые 5 секунд и хранится около 24 часов.

### Просмотр данных

![Просмотр данных](docs/imgs/data.png)

Дерево каталогов слева, таблица ключей в центре (ключ, превью значения, тип, размер), детали справа. Прокрутка списка подгружает следующие ключи.

В поиске можно писать tuple, не только hex:

```text
"M"
("M", uuid(3c6047fa-4f4e-466f-b349-49b72f5d6260), "l")
```

Поддерживаются строки, целые, числа с плавающей точкой, `true` / `false` / `null`, байты `0x`, `uuid(...)`, `float32(...)`, `Versionstamp(...)` и вложенные tuple. Префикс показывает ключи под ним; пустой запрос — пользовательское пространство ключей.

Значения классифицируются как JSON, текст, tuple или двоичные. Для 4- и 8-байтовых little-endian целых есть короткая подсказка. Полный текст и сворачиваемый hex — в панели деталей.

Запись:

- Создание, изменение и переименование точных ключей
- Удаление одного ключа или нескольких выбранных точных ключей (подтверждение; сервер требует `confirm: true`)
- Импорт / экспорт, резервное копирование / восстановление
- Наблюдение за ключом с обновлением при изменении значения

Диапазонного удаления нет.

### Конфигурация

![Конфигурация](docs/imgs/configuration.png)

Управление сохранёнными подключениями (добавить, переключить, удалить). Встроенное подключение из окружения удалить нельзя. Смена кластера очищает буфер тренда.

Для **подключённого** кластера можно менять режим избыточности, движок хранения и четыре счётчика ролей (commit proxies, GRV proxies, logs, resolvers). Координаторы, регионы, шифрование и режим арендаторов остаются в `fdbcli`.

## Сборка и тесты

```bash
make test
```

Запускаются пакеты без `libfdb_c`. Сборка Docker-образа выполняет `go test ./...`, включая `internal/fdbstore` (linux + cgo).

```bash
make build
make up
```

Версия приложения записывается при сборке образа (`APP_VERSION`, по умолчанию `1.0.0`).

## Лицензия

Это неофициальный клиентский интерфейс для FoundationDB. Сама FoundationDB распространяется на условиях Apple.
